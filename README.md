# Bootstrap Restaurant Website

## Overview

This project is a professional restaurant website developed using Bootstrap 5. The website includes a responsive navigation bar, menu section, featured dishes, booking form, and footer.

## Features

* Responsive Bootstrap 5 layout
* Navigation bar
* Restaurant menu cards
* Featured dishes section
* Table booking form
* Mobile-friendly design
* Modern user interface

## Technologies Used

* HTML5
* Bootstrap 5

## Learning Outcomes

* Learned Bootstrap Grid System
* Implemented responsive layouts
* Used Bootstrap components effectively
* Improved frontend design skills
